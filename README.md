One sentence a house cat would say in its own defence five seconds after sweeping a glass off the table — no apology, no confession, just the cat's own logic: the glass was blocking the view of the birds, and a cat does not negotiate with furniture.

> That glass was blocking my view of the birds, and I don't negotiate with furniture.

## Run it

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt` (83 characters, one line, one sentence).
